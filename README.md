# 📝 NotesVerse

NotesVerse is a full-stack note management web application that allows users to securely create, manage, and organize their personal notes. It provides user authentication with both traditional email/password login and Google OAuth.

## 🚀 Live Demo

🔗 **Live Application:** [NotesVerse](https://notesverse-q9qu.onrender.com/)

## 📂 GitHub Repository

🔗 **Repository:** https://github.com/Subirxgt/NotesVerse

---

## ✨ Features

- 🔐 User authentication and authorization
- 📧 Register and login using email and password
- 🔑 Secure password hashing using bcrypt
- 🔒 JWT-based authentication
- 🌐 Google OAuth 2.0 authentication
- 👤 User account management
- 📝 Create and manage personal notes
- 📱 Responsive user interface
- ☁️ Deployed on Render
- 🗄️ MongoDB database integration
- 🛡️ Protected routes for authenticated users
